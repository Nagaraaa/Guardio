Guardio 0.1.1 - Windows x64 / PS5 DualSense USB

Extract the whole ZIP into a writable folder and run Guardio.exe.
The standalone package includes .NET. The smaller framework-dependent
package requires the .NET 8 Desktop Runtime (x64).

The interface is currently in French:
- Keep "Proteger les branchements de la DualSense" checked.
- Choose your headset in Windows, then connect the controller over USB.
- "Sortie de secours": fallback if the previous output is unavailable.
- "Utiliser": explicitly choose the selected output, including the controller.
- "Reduire pres de l'horloge": keep running in the system tray.
- "Quitter" and the window close button both stop the program.

During the first two seconds after connecting the controller, a manual
controller choice in Windows can also be corrected. Use "Utiliser" in
Guardio or pause the protection in that case. A brief sound interruption
is possible on other PCs. Haptics and adaptive triggers have not been
validated in a compatible game. No audio device is disabled by the app.

Settings and diagnostic logs stay in donnees/ next to the executable.
No automatic Windows startup entry is installed. Quit and delete the folder
to uninstall. These executables are unsigned.
